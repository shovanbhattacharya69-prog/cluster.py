AUTOMOTIVE TELEMETRY ARCHITECTURE

This digital cockpit is a web-based twin of the Python Software-in-the-Loop instrument cluster contained in this repository. It models real vehicle dynamics (ecu_core.py), CAN 2.0B frame encoding and decoding using DBC definitions (automotive_network.dbc), and high-framerate cockpit rendering (cockpit_display.py).

ecu_core.py

Powertrain ECU node simulating 6-speed gear stepping, turbo spool dynamics, throttle response curves, and temperature models.

automotive_network.dbc

Standard CAN DBC specification defining 8-byte frames: ID 256 (PowertrainTelemetry) and ID 512 (VehicleDiagnostics).

cockpit_display.py

PyQt6 digital cluster canvas with QPainter drawing anti-aliased analog sweep dials, shift lights, and real-time DTC warning states.
